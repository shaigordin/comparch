Google Colab is a free, browser-based Python notebook. It runs on Google’s servers — nothing is installed on your computer. All you need is a Google account.

How Colab Works

A Colab notebook is made of cells. There are two types:

  • Text cells (like this module page) — explanations, instructions
  • Code cells — Python code that you can run by clicking the play button or pressing Shift+Enter

The output of each code cell appears directly below it.

The most important skill in this course

You do not need to write code. You need to: 1. Understand what analysis you want to run 2. Ask AI clearly to write that code 3. Paste it into a Colab code cell 4. Run it and interpret the output

The PEAR Prompt Framework

Talking to AI for data analysis works best when you are specific. The PEAR framework:

Letter Meaning Example
P Purpose — what are you trying to do? “I want to load a TPS file and run PCA on the landmark coordinates”
E Example — show the AI what your data looks like Paste the first few lines of your TPS file
A Action — what specific step do you need? “Write Python code to read this TPS file into a numpy array”
R Result — what output do you want? “And plot the landmarks as a scatter plot”

Example Prompt (bad):

“How do I analyze shape data?”

Example Prompt (good):

“I have a TPS file containing 2D landmark coordinates for 20 Roman coins, each with 8 landmarks. The file starts with: LM=8 / 123.4 456.7 / .... Write Python code using numpy to read this file and return a 3D array of shape (20, 8, 2).”

Your First Analysis: Loading the Coin Data

Open the Week 4 notebook and run the following AI-generated code:

# Cell 2: Load TPS data
# This code was generated by Claude when asked:
# "Write a Python function to read a TPS file and return a numpy array
#  of shape (n_specimens, n_landmarks, 2)"

import numpy as np

def read_tps(filepath):
    """Read a TPS file and return landmarks as (n, p, 2) array."""
    specimens = []
    current_lms = []
    n_lm = 0

    with open(filepath, 'r') as f:
        for line in f:
            line = line.strip()
            if line.startswith('LM='):
                n_lm = int(line.split('=')[1])
                current_lms = []
            elif line.startswith('IMAGE=') or line.startswith('ID='):
                if len(current_lms) == n_lm and n_lm > 0:
                    specimens.append(current_lms)
            elif line and not line.startswith('SCALE=') and not line.startswith('CURVES='):
                try:
                    coords = list(map(float, line.split()))
                    if len(coords) == 2:
                        current_lms.append(coords)
                except:
                    pass

    # Add last specimen
    if len(current_lms) == n_lm and n_lm > 0:
        specimens.append(current_lms)

    return np.array(specimens)

# Load Hadrian coins
hadrian = read_tps("data/coins/DEN_Hadrian/Hadrian.TPS")
print(f"Hadrian dataset: {hadrian.shape}")
# Expected output: (n_coins, 8, 2)
# Cell 3: Quick visualization of raw (unaligned) landmarks
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(8, 8))
for coin in hadrian:
    ax.scatter(coin[:, 0], coin[:, 1], alpha=0.3, s=15, color='steelblue')
ax.set_title("Raw (unaligned) Hadrian coin landmarks")
ax.set_aspect('equal')
plt.show()

What you will see: A cloud of points, messily scattered. Every coin is at a different position, size, and rotation. This is exactly why we need Procrustes alignment.
