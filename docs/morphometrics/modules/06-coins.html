Module 6: PCA — Exploring the Shape Space

Week 6 — The Toolkit

From 12 Dimensions to 2

After Procrustes alignment, each coin exists as a point in a 12-dimensional shape space. We cannot visualize 12 dimensions. Principal Components Analysis (PCA) solves this.

PCA finds the directions in shape space that capture the most variation. The first principal component (PC1) is the single axis that explains the most shape variation in the dataset. PC2 explains the most of what is left, and so on.

What PCA Is (Conceptually)

Imagine all your coins lying in a cloud of points in shape space. PCA finds the longest axis through this cloud (PC1), then the longest axis perpendicular to that (PC2), and so on.

By plotting PC1 vs. PC2, we capture the majority of shape variation in two dimensions we can see.

What PC scores mean

Each specimen gets a score on each PC axis. A high positive score on PC1 means the specimen has a lot of the shape variation described by PC1 (in the positive direction). A near-zero score means the specimen is close to the mean shape on that axis.

Shape Deformation Grids

The most powerful tool for interpreting PCA results is the thin-plate spline deformation grid.

A deformation grid shows how the mean shape must be deformed to produce the shape at any point in shape space. It is a visual map of the geometric transformation between two shapes.

Reading a deformation grid: - Regions where the grid is compressed → relative contraction toward the target shape - Regions where the grid is stretched → relative expansion toward the target shape - Grid lines that curve sharply → strong local deformation

We generate deformation grids using the morphops thin-plate spline functions.

# Cell 1: Import and setup
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
import numpy as np
import matplotlib.pyplot as plt
import pandas as pd

# Assume 'aligned' is our GPA result from Week 5
# Reshape: each specimen becomes one row
n = aligned.shape[0]
X = aligned.reshape(n, -1)  # shape: (n_coins, 16)

# PCA
pca = PCA()
scores = pca.fit_transform(X)
loadings = pca.components_  # shape: (16, 16)

# Variance explained
var_exp = pca.explained_variance_ratio_ * 100
print("Variance explained by first 5 PCs:")
for i, v in enumerate(var_exp[:5]):
    print(f"  PC{i+1}: {v:.1f}%")
# Cell 2: Scree plot — how many PCs matter?
plt.figure(figsize=(8, 4))
plt.bar(range(1, 8), var_exp[:7], color='steelblue', edgecolor='black')
plt.plot(range(1, 8), np.cumsum(var_exp[:7]), 'ro-', label='Cumulative %')
plt.xlabel("Principal Component")
plt.ylabel("Variance Explained (%)")
plt.title("Scree Plot — Hadrian Coins")
plt.legend()
plt.show()
# Cell 3: PCA scatter plot (PC1 vs PC2)
plt.figure(figsize=(8, 7))
plt.scatter(scores[:, 0], scores[:, 1],
            s=60, alpha=0.8, color='steelblue', edgecolor='white')

# Label outliers (bottom 5% and top 5% on PC1)
threshold = np.percentile(np.abs(scores[:, 0]), 95)
for i, (x, y) in enumerate(scores[:, :2]):
    if abs(x) > threshold:
        plt.annotate(f"Coin {i+1}", (x, y), fontsize=8,
                     xytext=(5, 5), textcoords='offset points')

plt.axhline(0, color='gray', linewidth=0.5, linestyle='--')
plt.axvline(0, color='gray', linewidth=0.5, linestyle='--')
plt.xlabel(f"PC1 ({var_exp[0]:.1f}% of variance)")
plt.ylabel(f"PC2 ({var_exp[1]:.1f}% of variance)")
plt.title("Shape Space: Hadrian Denarii")
plt.tight_layout()
plt.show()

Interpreting the PCA Plot

Look at your scatter plot and answer these questions:

  1. Spread: Do coins spread more along PC1 or PC2? What does this tell you about the dominant axis of shape variation?

  2. Clusters: Do you see any distinct groups, or is variation continuous?

  3. Outliers: Are there coins far from the main cloud? Go back and look at those coin images — is there something visually unusual about them?

  4. What does PC1 mean? We need a deformation grid to answer this properly — but make a visual guess based on coins at the positive vs. negative end of PC1.

Shape Deformation: What PC1 Actually Means

# Cell 4: Visualize shape at extreme PC1 values
import morphops as mops

mean_shape = aligned.mean(axis=0)

# Reconstruct shape at -2 SD and +2 SD on PC1
pc1_vector = loadings[0].reshape(-1, 2)  # PC1 as (8, 2) landmark shifts
std1 = np.sqrt(pca.explained_variance_[0])

shape_minus = mean_shape - 2 * std1 * pc1_vector
shape_plus  = mean_shape + 2 * std1 * pc1_vector

# Plot
fig, axes = plt.subplots(1, 3, figsize=(15, 5))

for ax, shape, title in zip(axes,
                              [shape_minus, mean_shape, shape_plus],
                              ["PC1 min (−2 SD)", "Mean shape", "PC1 max (+2 SD)"]):
    ax.scatter(shape[:, 0], shape[:, 1], s=80, color='steelblue')
    # Connect landmarks with lines (requires defining connectivity)
    ax.set_title(title)
    ax.set_aspect('equal')
    ax.set_xlim(-0.4, 0.4)
    ax.set_ylim(-0.4, 0.4)

plt.suptitle("Shape variation along PC1", fontsize=14)
plt.tight_layout()
plt.show()

What to look for: How do the landmark positions shift from the min to max shape? Which landmarks move most? What does this correspond to on the coin image?
