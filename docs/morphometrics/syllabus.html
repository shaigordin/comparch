Syllabus

Shape in Time: Geometric Morphometrics for Archaeologists — Spring 2026

Course Description

This course introduces undergraduate students in archaeology and history to the theory and practice of geometric morphometrics (GM) — the quantitative study of shape in objects made by human hands. Students work with published open-access datasets of Roman coins, Bronze Age flanged axes, and ancient pottery, using AI-written code in Google Colab (no installation required) to run all analyses.

No prior programming experience is assumed or required. A computer with internet access is all you need.

Learning Outcomes

By the end of the semester, students will be able to:

  1. Explain what geometric morphometrics is and how it differs from traditional typological description
  2. Distinguish between landmark, semi-landmark, and outline methods, and know when to apply each
  3. Use AI tools (Claude, ChatGPT) to generate, run, and annotate Python code for shape analysis in Google Colab
  4. Perform Generalized Procrustes Analysis (GPA) and interpret aligned shape configurations
  5. Run and interpret Principal Components Analysis (PCA) on shape data, including deformation grids
  6. Apply Elliptic Fourier Analysis (EFA) to outline data
  7. Apply basic permutation-based statistical tests to compare shape groups
  8. Connect shape patterns to archaeological questions of production, exchange, identity, and chronology
  9. Present and critically evaluate GM-based archaeological research

Lecture (90 min):

  • What shape can and cannot tell us
  • Tour of the three case studies: coins, axes, pottery

Archaeological framing:

  • Coins: Roman Imperial standardization and mint identity
  • Axes: Bronze Age craft networks and typological groupings
  • Pottery: ceramic production traditions and exchange

Reading (light — provided as excerpts):

Lecture (90 min):

  • Inter-observer error — the hidden problem in all landmark studies

Week 5: Procrustes Alignment — Putting Shapes in the Same Space

Lecture (90 min):

  • The core problem: before we can compare shapes, we must remove the effect of size, position, and rotation
  • Generalized Procrustes Analysis (GPA): the algorithm in plain language
    1. Translate all configurations to the same centroid
    2. Scale to unit centroid size
    3. Rotate to minimize total squared distance between corresponding landmarks
  • Centroid size: what it is and why it’s the measure of scale in GM
  • The Kendall shape space and why we work in its tangent plane
  • Visualizing aligned configurations: the consensus (mean) shape

Lab (30 min):

Open the Week 5 Colab notebook. AI generates the GPA code:

# Generalized Procrustes Analysis on all coins
gpa_result = mops.procrustes_fit(lms)
aligned = gpa_result[0]    # aligned coordinates
centroid_sizes = gpa_result[1]  # one size value per specimen

# Plot all aligned configurations
fig, ax = plt.subplots(figsize=(8, 8))
for config in aligned:
    ax.scatter(config[:, 0], config[:, 1], alpha=0.3, s=10, color='gray')
mean_shape = aligned.mean(axis=0)
ax.scatter(mean_shape[:, 0], mean_shape[:, 1], s=80, color='red', zorder=5)
ax.set_title("GPA-aligned coin landmarks (red = mean shape)")
plt.show()

Week 6: PCA — Exploring the Shape Space

Lecture (90 min):

  • What PCA does: finding the axes of maximum variation in a high-dimensional dataset
  • PC axes are directions in shape space; PC scores tell us where each specimen sits
  • How to read a PCA scatter plot: clusters, gradients, outliers
  • Shape deformation grids: thin-plate splines to visualize what PC1 and PC2 actually mean morphologically
  • Common mistakes: over-interpreting PCA, treating PC axes as “real” biological factors

Lab (30 min):

AI-generated PCA code in the Week 6 Colab notebook:

from sklearn.decomposition import PCA
import pandas as pd

# Reshape aligned landmarks for PCA (each specimen = one row)
n = aligned.shape[0]
X = aligned.reshape(n, -1)

# PCA
pca = PCA(n_components=10)
scores = pca.fit_transform(X)

print("Variance explained per PC:")
for i, v in enumerate(pca.explained_variance_ratio_[:5]):
    print(f"  PC{i+1}: {v*100:.1f}%")

# Plot PC1 vs PC2
plt.figure(figsize=(8, 6))
plt.scatter(scores[:, 0], scores[:, 1], alpha=0.7)
plt.xlabel(f"PC1 ({pca.explained_variance_ratio_[0]*100:.1f}%)")
plt.ylabel(f"PC2 ({pca.explained_variance_ratio_[1]*100:.1f}%)")
plt.title("PCA of Roman coin shapes")
plt.show()

  • The Hadrian (r. 117–138 CE) and Antoninus Pius (r. 138–161 CE) denarii: context
  • Research question: Did die cutters maintain consistent shape standards across emperors? Do portrait types cluster by issuer?
  • Reading a GM paper critically: what to look for in methods and results

Lab (60 min):

Assignment 3 due. Assignment 4 distributed: Bronze Age Axes Outline Analysis

Unit III — Outlines and the Bronze Age (Weeks 8–9)

Week 8: Outline Analysis — Elliptic Fourier Analysis

Lecture (90 min):

  • When landmarks aren’t enough: objects without discrete homologous points
  • What an outline is: a closed contour captured as a sequence of x,y coordinates
  • Elliptic Fourier Analysis: decomposing an outline into a sum of elliptic harmonics
    • Analogy: like breaking down a musical chord into individual notes
    • The first harmonic captures basic size/shape; higher harmonics add detail
  • Choosing the number of harmonics: the variance explained criterion
  • Normalizing for size, position, rotation, and starting point
  • How EFA + PCA gives us the same kind of shape space as landmark GM

Reading (provided):

  • Bonhomme, V. et al. (2014). Momocs: Outline analysis using R. Journal of Statistical Software 56(13):1–24. [Introduction and methods sections]

Lab (30 min):

First look at the flanged axes dataset. Load outlines in the Week 8 Colab notebook:

import pyefd
from skimage import io, measure, color
import numpy as np

# Load a single axe outline image and extract contour
img = io.imread("axes/ALT.tif", as_gray=True)
contours = measure.find_contours(img, 0.5)
outline = contours[0]  # largest contour

# Fit EFA (12 harmonics)
coeffs = pyefd.elliptic_fourier_descriptors(outline, order=12, normalize=True)
print(f"EFA coefficients shape: {coeffs.shape}")  # (12, 4)

Week 11: Testing Hypotheses — Statistics in Shape Space

Lecture (90 min):

  • Why standard t-tests and ANOVAs don’t work for shape data
  • Permutation tests: the logic and why they are appropriate for GM
  • MANOVA in shape space: testing for group differences
  • Effect sizes: R² and what it means
  • Allometry: does shape change with size? How to test this
  • Multiple comparisons: what to do when you have many groups
  • What “statistically significant” actually means — and what it doesn’t

  2. Run GPA on the combined dataset
  3. Run PCA — produce a scatter plot color-coded by emperor
  4. Run a permutation-based shape comparison
  5. Produce mean shape deformation grids for each group

Write a 500-word interpretation: - Do the two emperors’ coins cluster separately in shape space? - What specific shape differences do you see in the deformation grids? - What might explain any similarities or differences? Think about: die standardization, mint organization, imperial conventions.

Deliverables: Link to Colab notebook + 600-word PDF + map image.

Assignment 5 — Pottery PCA (5%)

A deliberately lighter exercise — focus on interpretation, not code.

Using the Week 10 Colab notebook (pre-built pipeline), load the pottery dataset, run EFA + PCA, and produce one well-labeled scatter plot. Write a 300-word interpretation connecting the shape patterns to what you know about the archaeological context.

Deliverable: One plot (PNG) + 300-word interpretation as PDF.

The final project asks you to go deeper on a shape question of your choice.

For students who prefer writing over data analysis: write a detailed research proposal (3000 words) for a GM study on an artefact type of your choice. Must include: research question, dataset design, expected methods, predicted results, and critical reflection on limitations. Minimum 8 references.

  • Figures: Minimum 3 (PCA plot, deformation/EFA shape visualization, one additional)
  • Code: Submit your Colab notebook link as an appendix
  • References: Minimum 8 peer-reviewed sources

AI Policy

This course explicitly encourages AI tools for code writing. You are expected to:

  1. Use Claude or ChatGPT to generate Python code in Colab — this is part of the design
  2. Understand the analysis conceptually (not line-by-line syntax)
  3. Be able to explain your results in your own words
  4. Annotate AI-generated code with brief comments explaining what each block does
  5. Never use AI to write your interpretation or essay text

AI is your lab assistant. You are the archaeologist.

```python
ax.scatter(mean_shape[:, 0], mean_shape[:, 1], s=80, color='red', zorder=5)
ax.set_title("GPA-aligned coin landmarks (red = mean shape)")
plt.show()
```

#### Week 6: PCA — Exploring the Shape Space

**Lecture (90 min):**

- What PCA does: finding the axes of maximum variation in a high-dimensional dataset
- PC axes are directions in shape space; PC scores tell us where each specimen sits
- How to read a PCA scatter plot: clusters, gradients, outliers
- **Shape deformation grids:** thin-plate splines to visualize what PC1 and PC2 actually mean morphologically
- Common mistakes: over-interpreting PCA, treating PC axes as "real" biological factors

**Lab (30 min):**

AI-generated PCA code in the **Week 6 Colab notebook**:

```python
from sklearn.decomposition import PCA
import pandas as pd

# Reshape aligned landmarks for PCA (each specimen = one row)
n = aligned.shape[0]
X = aligned.reshape(n, -1)

# PCA
pca = PCA(n_components=10)
scores = pca.fit_transform(X)

print("Variance explained per PC:")
for i, v in enumerate(pca.explained_variance_ratio_[:5]):
    print(f"  PC{i+1}: {v*100:.1f}%")

# Plot PC1 vs PC2
plt.figure(figsize=(8, 6))
plt.scatter(scores[:, 0], scores[:, 1], alpha=0.7)
plt.xlabel(f"PC1 ({pca.explained_variance_ratio_[0]*100:.1f}%)")
plt.ylabel(f"PC2 ({pca.explained_variance_ratio_[1]*100:.1f}%)")
plt.title("PCA of Roman coin shapes")
plt.show()
```

#### Week 8: Outline Analysis — Elliptic Fourier Analysis

**Lecture (90 min):**

- When landmarks aren't enough: objects without discrete homologous points
- What an outline is: a closed contour captured as a sequence of x,y coordinates
- Elliptic Fourier Analysis: decomposing an outline into a sum of elliptic harmonics
  - Analogy: like breaking down a musical chord into individual notes
  - The first harmonic captures basic size/shape; higher harmonics add detail
- Choosing the number of harmonics: the variance explained criterion
- Normalizing for size, position, rotation, and starting point
- How EFA + PCA gives us the same kind of shape space as landmark GM

**Reading (provided):**

- Bonhomme, V. et al. (2014). Momocs: Outline analysis using R. *Journal of Statistical Software* 56(13):1–24. [Introduction and methods sections]

**Lab (30 min):**

First look at the flanged axes dataset. Load outlines in the **Week 8 Colab notebook**:

```python
import pyefd
from skimage import io, measure, color
import numpy as np

# Load a single axe outline image and extract contour
img = io.imread("axes/ALT.tif", as_gray=True)
contours = measure.find_contours(img, 0.5)
outline = contours[0]  # largest contour
```
