כיצד לכתוב פרומפטי AI טובים (מהדורה מהירה)

השתמשו במסגרת PEAR:

P — Purpose: "אני רוצה להשוות שתי קבוצות של צורות מטבע..."
E — Example: "הנתונים שלי נראים כך: [הדביקו 5 שורות ראשונות או צורת מערך]"
A — Action: "כתבו קוד Python ש..."
R — Result: "...ויפיק גרף פיזור מסומן עם מקרא"

איטרציה היא נורמלית. הקוד שנוצר ראשית על ידי AI עשוי לדרוש ניפוי באגים. הדביקו את הודעת השגיאה חזרה ל-AI ובקשו ממנו לתקן את הבעיה.

אם נתקעתם

  1. קראו מחדש את דף המודול — דוגמאות הקוד שם פועלות על נתוני הקורס
  2. שאלו את ה-AI להסביר לכם את הודעת השגיאה
  3. גגלו את השגיאה — ב-Stack Overflow יש פתרונות לכמעט כל שגיאת Python
  4. פרסמו בפורום הקורס — כללו את הודעת השגיאה וצילום מסך של התאים הרלוונטיים
  5. בואו לשעות קבלה

## כיצד לכתוב פרומפטי AI טובים (מהדורה מהירה)

השתמשו במסגרת **PEAR**:

```
P — Purpose: "אני רוצה להשוות שתי קבוצות של צורות מטבע..."
E — Example: "הנתונים שלי נראים כך: [הדביקו 5 שורות ראשונות או צורת מערך]"
A — Action: "כתבו קוד Python ש..."
R — Result: "...ויפיק גרף פיזור מסומן עם מקרא"
```

**איטרציה היא נורמלית.** הקוד שנוצר ראשית על ידי AI עשוי לדרוש ניפוי באגים. הדביקו את הודעת השגיאה חזרה ל-AI ובקשו ממנו לתקן את הבעיה.
