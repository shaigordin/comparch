How to Write Good AI Prompts (Quick Reference)

Use the PEAR framework:

P — Purpose: "I want to compare two groups of coin shapes..."
E — Example: "My data looks like this: [paste first 5 rows or array shape]"
A — Action: "Write Python code that..."
R — Result: "...and produce a labeled scatter plot with legend"

Iteration is normal. Your first AI-generated code may need debugging. Paste the error message back to the AI and ask it to fix the problem.

If You Get Stuck

  1. Re-read the module page — the code examples there work on the course data
  2. Ask the AI to explain the error message to you
  3. Google the error — Stack Overflow has solutions to almost every Python error
  4. Post in the course forum — include your error message and a screenshot of the relevant cells
  5. Come to office hours
