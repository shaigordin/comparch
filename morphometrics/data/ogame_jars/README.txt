Title
A Geometric Morphometric Dataset of Edo-Period ‘Ogame’ Jar Profiles from Northern Kyushu, Japan

Paper Authors
Loftus, James Frances
Institute of Science Tokyo

Abstract
This dataset contains 243 silhouette images of Edo-period Ogame (“large jar”) vessels from Hizen and Chikuzen Provinces (modern-day Saga and Fukuoka prefectures), Japan. These thick-walled stoneware jars served diverse functions, from storing soy sauce and fertilizer to containing human remains in burials. The silhouettes were extracted from archaeological site reports and prepared for outline-based Geometric Morphometric (GMM) analysis, a method that quantifies shape independently of size or landmarks. By enabling replicable shape analysis of large, curvilinear ceramic forms, this dataset supports research into morphological standardization, workshop practice, and the intersection of political economy and material culture in early modern Japan.

Dataset description

Object name
Ogame_GMM.zip – A zip file containing all below files and folders;
Ogame_Samples.csv – An Excel spreadsheet containing sample metadata, including sample ID, site names, depositional context, site report ID and page numbers of corresponding samples; 
Ogame_Sites.csv – An Excel spreadsheet containing site metadata, including site names, coordinates, excavation dates, depositional context, and publication sources (site reports); 
Ogame_Profiles_All – A single folder containing 243 black-and-white profile images (.png) of Ogame jars; 
Ogame_Profiles_Site – A folder containing the same 243 profile images (.png), organized by individual site subfolders using site IDs

Data type
Primary data, Processed data

Format names and versions
PNG (.png) – standardized vessel profiles; Excel (.csv) – sample and site metadata

Creation dates
Initial dataset compilation and indexing began in 2022 during the author’s postdoctoral research at Kyushu University, following the excavation and analysis of Edo-period burial contexts. The dataset was further expanded between 2024 and 2025 using publicly available archaeological site reports accessed via the Nara National Research Institute for Cultural Properties’ online site report archive (now the ‘Comprehensive Database of Cultural Heritage in Japan’: https://sitereports.nabunken.go.jp/en).

Reuse potential
The dataset offers a ready-to-use resource for testing computational shape analysis methods on complex, non-landmarked vessel forms. Its consistent formatting allows researchers to directly apply Geometric Morphometric workflows (e.g., Elliptical Fourier Analysis) without preprocessing, making it ideal for cross-study comparisons. Beyond morphometrics, the profiles can support studies on ceramic production systems, depositional patterning, or the visual encoding of vessel function during premodern Japan. The dataset also lends itself to pedagogy in digital archaeology, offering a clean, curated dataset for classroom instruction or methodological replication, regardless of the medium used (coding or designated GMM software).
